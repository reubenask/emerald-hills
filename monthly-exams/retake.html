Section Retake

Use this when a machine, microphone or audio problem spoiled one section of a submitted test. The student retakes only that section, and its new marks replace that section in the original report, which is emailed again.

1. Find the test

2. Choose the section

Writing and speaking can be retaken task by task. Untick the tasks that worked; leave all ticked to retake the whole section.

3. Give the student the retake

Open this link on the student's computer. It opens only that section, with the student's name, class and date filled in.

The code works once, for this student and this section only, and expires . If the retake is not submitted in time, create a new code.
