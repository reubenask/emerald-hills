Teacher Page

Use this on your own device. See every student's full report, check and approve the marks, and allow a retake when a machine, microphone or audio problem spoiled part of a test. The emails are a copy for your records.

All Reports

Every submitted test, newest first. Red lines need you: a missing or silent recording, marking that failed, or a mark the AI was unsure about. Open the full report to check the marks, change any you disagree with, and approve it.

Started but not sent ()

These tests were started in the last two weeks but never sent: the student did not press Submit All, or did not tick the consent box. Only the student's computer has their answers.

1. Choose the test to retake

A student asks with Request a Retake on their submitted test and shows you the request code on their screen.

No request? Find the test by name

2. Choose what to retake

Writing and speaking can be retaken task by task. For a request, the student's choice is ticked already; change it if needed.

3. Approved

The student's test page now shows Start Retake. Nothing needs to be typed on their computer, and the retake works only on the computer that asked for it.

3. Give the student the retake

Open this link on the student's computer. It opens only that part of the test, with the student's name, class and date filled in.

The code works once, for this student and this section only, and expires . If the retake is not submitted in time, create a new code.
