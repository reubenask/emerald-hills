Section Retake

Use this on your own device when a machine, microphone or audio problem spoiled part of a submitted test. The student retakes only that part, and its new marks replace the old ones in the original report, which is emailed again.

1. Choose the test

A student asks with Request a Retake on their submitted test and shows you the request code on their screen.

No request? Find the test by name

2. Choose what to retake

Writing and speaking can be retaken task by task. Untick the tasks that worked; leave all ticked to retake the whole section.

3. Approved

The student's test page now shows Start Retake. Nothing needs to be typed on their computer, and the retake works only on the computer that asked for it.

3. Give the student the retake

Open this link on the student's computer. It opens only that part of the test, with the student's name, class and date filled in.

The code works once, for this student and this section only, and expires . If the retake is not submitted in time, create a new code.
